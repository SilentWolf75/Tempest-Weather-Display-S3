Tempest Weather Display S3

High-end standalone weather console for the Waveshare ESP32-S3-Touch-AMOLED-1.75 circular display. Direct LAN UDP listening & Cloud REST failover for WeatherFlow Tempest stations.
⚡ 1-Click Browser Installer

Flash your ESP32-S3 board directly from Google Chrome or Microsoft Edge via Web Serial — no PlatformIO or command line required!

Use Chrome or Edge on desktop (Web Serial is required). Web Serial requires HTTPS.
Installs: bootloader.bin · partitions.bin · boot_app0.bin · firmware.bin
📖 Quick Setup Steps
  1. Connect the Waveshare ESP32-S3 AMOLED board to your computer using a USB-C data cable.
  2. Click Install Firmware above and choose the USB JTAG/serial or USB Serial port in the browser popup.
  3. For a first-time flash, check Erase device to ensure a clean partition setup.
  4. Once the flash completes, the device will reboot and broadcast a setup Wi-Fi hotspot: Weather-Display-Setup.
  5. Connect your phone or laptop to Weather-Display-Setup and open http://192.168.4.1/ to select your Wi-Fi network and save your Tempest Station ID.
  6. After connecting to your Wi-Fi, open the live web dashboard at http://weather.local/ to configure real-time brightness, auto-dim timeouts, rotation, and units!
💡 Updating existing firmware? Leave "Erase device" unchecked to preserve your existing Wi-Fi credentials and station configuration in NVS flash.
