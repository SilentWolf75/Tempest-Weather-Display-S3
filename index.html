Tempest Weather Display S3 & P4

A standalone weather console for the Waveshare S3 1.75" AMOLED and P4 4" LCD circular displays. Direct LAN UDP listening & Cloud REST failover for WeatherFlow Tempest stations.
⚡ 1-Click Browser Installer

Flash your supported Waveshare S3 AMOLED or P4 LCD board from Google Chrome or Microsoft Edge. The installer selects firmware for the connected chip.

Use Chrome or Edge on desktop (Web Serial is required). Web Serial requires HTTPS.
Installs: bootloader.bin · partitions.bin · boot_app0.bin · firmware.bin
📖 Quick Setup Steps
  1. Connect your supported Waveshare S3 AMOLED or P4 LCD board with a USB-C data cable.
  2. Click Install Firmware above and choose the USB JTAG/serial or USB Serial port in the browser popup.
  3. For a first-time flash, check Erase device to ensure a clean partition setup.
  4. Once the flash completes, the device will reboot and broadcast a setup Wi-Fi hotspot: Weather-Display-Setup.
  5. Join Weather-Display-Setup using the Setup key shown on the display. Open http://192.168.4.1/, sign in as admin with that same key, and save your Wi-Fi network.
  6. After connection, open http://weather.local/ to enter your Tempest Station ID and API token, and adjust display settings. Both boards rotate in 90° steps. The P4 applies that rotation in software, and its natural orientation is 0°.
💡 Updating existing firmware? Leave "Erase device" unchecked to preserve your existing Wi-Fi credentials and station configuration in NVS flash.
